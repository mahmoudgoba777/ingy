FREE PUBLISHING WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a public repository named nnc-ingy-contact.
3. Upload all contents of this folder; index.html must be at repository root.
4. Go to Settings > Pages.
5. Under Build and deployment select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for the published URL. It should look like:
   https://YOUR-USERNAME.github.io/nnc-ingy-contact/

Generate a final QR only after publishing, using the exact live URL.
